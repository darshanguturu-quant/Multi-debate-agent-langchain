# Multi-Agent AI Debate System

## Overview
A Multi-Agent AI Debate System built using LangChain, RAG, FAISS, and LLMs. Multiple AI agents debate, critique, and validate responses before producing a final answer.

## Features
- Retrieval-Augmented Generation (RAG)
- FAISS Vector Search
- Multi-Agent Debate Framework
- Semantic Retrieval
- Response Validation
- Reduced Hallucinations

## Tech Stack
- Python
- LangChain
- FAISS
- Hugging Face
- Groq
- Together AI

## Architecture

User Query
↓
Retriever (FAISS)
↓
Agent 1 (Proposer)
↓
Agent 2 (Critic)
↓
Agent 3 (Verifier)
↓
Final Answer
